Summary

Phorcysty is an AI-powered media editing application that processes selected images and videos to provide features such as AI color transfer, cinematic enhancement, video processing, and image upscaling.

The app may process selected media on secure servers when server-side AI processing is required. Media is used only to provide the requested processing and is not used to train AI models.

The app may also process limited technical, device, crash, and advertising-related information through third-party services such as Firebase Crashlytics and Unity Ads, as described in this Privacy Policy.

Welcome to Phorcysty, an AI-powered media processing application operated by Asagneya. Phorcysty is designed to help users apply advanced color transfer, color style transformation, cinematic enhancement, and image upscaling using artificial intelligence and media processing technologies.

Our application provides AI-based processing across different types of media. The main features include:

  • Image-to-Image color transfer
  • Video-to-Video color transfer
  • Image-to-Video color transfer
  • Video-to-Image color transfer
  • Image upscaling

These features allow users to apply the color style of one image or video to another while preserving the original structure and content of the media. The upscaling feature is available for supported images and uses server-side AI processing to upscale the selected image and return an enhanced high-resolution result.

In addition to AI processing, Phorcysty provides professional adjustment tools that let users fine-tune their media, including:

  • Contrast
  • Brightness
  • Saturation
  • Hue
  • Temp
  • Tint

To deliver these functionalities, Phorcysty uses a trusted pre-trained AI model that processes media efficiently and securely. We do not sell, rent, or misuse your personal data. Our primary goal is to provide high-quality color transformation and enhancement tools for creative and professional use.

Phorcysty may use trusted third-party services such as Google Firebase. These services may collect limited technical information (such as device identifiers, crash reports, and usage statistics) to help improve app performance and ensure application stability.

By using Phorcysty, you agree to the collection and use of information in accordance with this Privacy Policy.

This application is available on the Google Play Store and is intended for users aged 13 years and above, or the minimum age required by applicable laws in your country.

Downloads & Export Formats

Phorcysty allows users to save processed media to their device when they choose the Download or Export option.

Image Export Formats:
Supported image export formats include:

  • PNG
  • JPG/JPEG
  • WEBP
  • SVG

SVG Export:
The SVG export option stores the processed image within an SVG file using embedded PNG image data. This export does not convert the image into independent editable vector paths.

When a user downloads or exports a result, the resulting file is saved to the device using Android's supported media-storage mechanisms. The saved file remains under the user's control and can be managed or deleted using the device's normal file or gallery management features.

User-Initiated Downloads:
Phorcysty does not automatically save processed media to the device. Saving or exporting a result occurs only after the user initiates the corresponding Download or Export action.
